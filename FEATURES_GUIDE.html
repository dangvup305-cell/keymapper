KeyMapper 按键映射

把物理键盘按键映射成屏幕点击 / 长按 / 滑动 / 双指缩放；游戏向增强：可调键位、长按连发、换装备序列宏、循环连点器

版本 v1.1 · 2026-08-19 · 适配 一加 13 / 一加 Pad 3（ColorOS 15 / Android 15）

一、双模式架构

一个 App、两套能力，共用同一个无障碍服务（按键监听 + 手势注入）与悬浮层。

二、功能总览

三、快速上手（首次使用）

安装 APK→ 开启无障碍服务→ 授权悬浮窗→ 关闭电池优化→ 启动悬浮窗→ 开始映射
  • 设置 → 无障碍 → KeyMapper 按键映射服务 → 开启（核心权限，不开无法触发）
  • 悬浮窗权限：设置页点「去开启」授权（SYSTEM_ALERT_WINDOW）
  • 通知权限（Android 13+）：授权后保活通知常驻
  • 一加 / ColorOS：设置页「ColorOS 保活设置」一键关闭电池优化 + 允许自启动 / 多任务锁定

四、操作说明

4.1 基本映射（点击 / 长按 / 滑动 / 双指缩放）

  • 悬浮球 → 「开始映射」进入全屏覆盖层（或主界面「开始映射」）
  • 点击屏幕记录坐标 → 按下要绑定的物理键（可先按修饰键再按主键 = 组合键）
  • 长按已生成的标记可：删除 / 重绑键 / 改颜色 / 改触发类型（滑动需再点一次终点）/ 调整大小 / 连发开关
  • 点「保存配置」命名落盘，即成为当前生效配置

4.2 可调键位大小 · 拖动微调 · 网格吸附

  • 大小：映射模式长按标记 → 「调整大小」（4–40dp，大标记命中范围自动变大）；运行态悬浮层长按标记同样可调
  • 拖动微调：悬浮面板长按「隐藏/显示绑定点」进入管理态 → 直接拖动标记到目标位置，松手自动保存
  • 网格吸附：映射模式底部「网格吸附：开/关」；开启后采点与拖动自动对齐 20dp 网格，避免键位重叠

4.3 长按连发（移动 / 持续施法）

  • 长按标记 → 「长按连发：开」：按住物理键按 100ms 间隔持续触发，松开即停；短按仍是一次普通触发

4.4 换装备序列宏 + 音量键触发

  • 映射模式选好坐标后按音量键（Vol+ / Vol-）绑定；未绑定动作时音量键照常调音量
  • 长按该标记 → 「修改触发类型」→ 「宏指令」→ 进入宏编辑器
  • 在画面上点击添加「点击」步骤、按住拖动添加「滑动」步骤；底部可调统一间隔 / 删步骤
  • 「完成」→ 保存配置。游戏中按音量键即一次性执行换装序列（跑完即停，不占用后续输入）

4.5 循环连点器（模式二）

  • 入口：悬浮面板「连点器」/ 通知栏「连点器」按钮
  • 点击屏幕添加 1~N 个连点坐标（带序号圆点）→ 设间隔(ms) / 次数(0=无限) / 时长秒(0=不限)
  • 「开始连点」自动收起页面后台循环点击；次数 / 时长到达自动停
  • 停止：悬浮窗「■ 停止连点」小按钮 / 重进连点器页点停止 / 无障碍服务断开自动停

4.6 快捷入口与配置管理

  • 快捷磁贴：下拉通知栏「悬浮窗开关」磁贴（需先手动添加到快捷设置）
  • 配置面板：主界面「配置管理」→ 载入 / 删除 / 测试映射；悬浮面板「加载配置 ▾」快速切换
  • 测试模式：命中绑定只高亮不注入，确认键位不误触后关闭

五、重新出包与安装

  • Android Studio 打开 KeyMapper/ → 等待 Gradle 同步（自动补 wrapper）
  • 菜单 Build → Build Bundle(s)/APK(s) → Build APK(s)
  • 产物：app/build/outputs/apk/debug/app-debug.apk
  • 安装：adb install -r app-debug.apk（或传到手机直接安装）
覆盖安装不丢已保存的配置（存于应用私有目录）；新装请重新完成授权。
